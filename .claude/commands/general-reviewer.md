# General codebase review

This reviews the **entire codebase**, not a diff. Review only - do not edit
any file as part of this command.

## Establish scope

Run:

```bash
git ls-files --cached --others --exclude-standard | grep -v '^\.boost/'
```

This lists every tracked file plus any untracked-but-not-gitignored file,
which already excludes `.venv/`, `__pycache__/`, `.pytest_cache/`, `data/*`
(personal job-search data, not code), and `.env` via `.gitignore` - and the
`grep -v` drops Boost's own cache dir, which isn't gitignored but also
isn't project code. If this repo ever gains a `node_modules/`, build output
dir, or a dependency lock file, exclude those too before continuing -
`requirements*.txt` stay in scope here since they're hand-maintained, not
autogenerated locks.

State the resulting file list plainly in your own words before continuing
- the four reviewers launched next are fresh agents and need it restated
verbatim in their prompts, not a reference back to this output.

## Run the review

Load the `combined-review` skill with the Skill tool and follow it against
the file list just established.
